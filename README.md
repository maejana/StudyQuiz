# 🧠  StudyQuiz Quizspiel (HTML / CSS / JavaScript)

Ein leichtgewichtiges, im Browser laufendes Quizspiel.   
Ideal zum schnellen Lernen oder einfach nur zum Spaß.

---

## 🚀 Features
- **Reaktions­schnelle Web‑App** – läuft in jedem modernen Browser
- **Mehrere Frage­typen**: Multiple Choice, Wahr/Falsch, Freitext  
- **Punkte‑ & Zeit­wertung** (konfigurierbar)
- **Progress‑Bar** zeigt den Quiz‑Fortschritt
- **Responsives Design** – spielbar auf Desktop, Tablet & Smartphone
- **Leicht erweiterbar**: Fragen in `questions.json` anpassen oder per API laden
